# Changelog

## 1.0.0

Initial public release.

### Added

- Home Assistant app/add-on wrapper for Batrium WatchMon UDP Listener.
- Host networking support for LAN UDP broadcast packets.
- Persistent `/data/config.json` handling.
- Runtime copy to `/app/config/config.json`.
- Home Assistant Ingress web UI for editing JSON config.
- JSON validation, formatting and reload from disk.
